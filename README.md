# Индивидуальный проект

## Тема проекта - Сервис поиска исполнителей

## Предполагаемые сущности: заказчик, исполнитель, отклик, заказ, счёт, банковская транзакция, отзыв

## Основной сценарий поиска исполнителя: регистрация заказчика -> публикация заказа -> отклик со стороны исполнителя -> выполнение заказа -> оплата -> отзыв

## Предполагаемый стек: Django, DRF, Postgresql
